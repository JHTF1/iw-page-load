# 实验记录

每次采集或受控实验都必须登记。这份记录是报告"实验严密"章节的原始证据，也是答辩时解释异常的依据。

---

## 一、记录规则

- 一次实验（一个批次）一条记录，不按站点逐条记
- 实验开始前先填"计划"部分，结束后补"结果"部分
- 任何异常剔除都要写清规则和数量
- 换了网络、换了机器、换了时段，必须另起一条记录

## 四、必须记录的控制变量

真实站点实验：

- 同一台机器、同一网络、同一时段窗口
- 浏览器禁用 QUIC
- 冷缓存
- 固定重复轮数（默认 5 轮）
- 抓包与加载测量分开执行

受控实验：

- WSL 版本与内核版本
- `tc netem` 的延迟参数
- `ip route` 的 initcwnd 设定值
- 测试页面对象数与单对象大小
- 每组重复轮数

---

## 五、异常与剔除

- 剔除规则：四分位距（IQR），超出 `Q1 - 1.5×IQR` 到 `Q3 + 1.5×IQR` 视为异常
- 必须记录：剔除发生在哪个站点、第几轮、剔除前后的样本数
- 站点整体不可达：记录原因（DNS 失败、超时、证书错误），从统计中剔除，并在报告里说明

- 抓包时长：每轮 tcpdump 最长 8 秒
- initcwnd 设定值：2 / 4 / 10 / 20 MSS
- 请求 URL：http://172.21.76.52:8080/obj-01.png（60 KB 单对象，足以填满首窗口）

结果：
- 成功站点数：4 组 × 5 轮 = 20 轮全部成功
- 失败站点及原因：无
- 异常剔除规则与数量：无剔除

- 测量结果：lab-2 = 2784 B / 1392 B = 2.0 MSS；lab-4 = 5568 B / 1392 B = 4.0 MSS；lab-10 = 13920 B / 1392 B = 10.0 MSS；lab-20 = 27840 B / 1392 B = 20.0 MSS；四组均为 confidence=high，误差 0 MSS
- 校准发现：客户端 SYN 报 MSS 1460，服务器 SYN-ACK 报 1392（WSL eth0 MTU 1432），服务器实际按 1392 B 发包。原算法只取客户端 MSS，lab-10 会算成 9.53；改为取两端 MSS 较小值后精确为 10.0。百度真实 pcap 同样存在客户端 1460、服务器 1360 的差异，CSV 已由 3.57 修正为 3.83 MSS
- 结论或观察：四组已知真值全部精确复现，算法通过 11/03 质量关卡；可以进入 11/04 真实站点 25 站全量抓包

备注：
- 校准前将本机 WSL 从 mirrored 临时切到 NAT，使 `tc netem` 与 `ip route initcwnd` 作用于 eth0；完成后已清除 netem、恢复 initcwnd=10，并切回 mirrored
- 受控平台脚本沿用 experiment/server/ 下 B 的 set_netem.sh、set_initcwnd.sh 与 gen_page.py；nginx 测试页安装在 WSL Ubuntu 的 /var/www/lab
