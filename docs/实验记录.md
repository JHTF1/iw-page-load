# 实验记录

每次采集或受控实验都必须登记。这份记录是报告"实验严密"章节的原始证据，也是答辩时解释异常的依据。

---

## 一、记录规则

- 一次实验（一个批次）一条记录，不按站点逐条记
- 实验开始前先填"计划"部分，结束后补"结果"部分
- 任何异常剔除都要写清规则和数量
- 换了网络、换了机器、换了时段，必须另起一条记录

---

## 二、记录模板

复制下面这段，追加到文末：

```
### 记录编号：EXP-YYYYMMDD-NN

日期：
执行人：
实验类型：真实站点 / 受控实验 / 算法校准

环境：
- 机器：
- 操作系统：
- 网络：有线 / 无线，运营商，带宽
- 抓包后端：WinPcap 4.1.3 / WSL tcpdump
- 浏览器：Chrome 版本
- WSL 版本（受控实验填）：

计划：
- 站点数量：
- 每站重复轮数：
- 抓包时长：
- initcwnd 设定值（受控实验填）：

结果：
- 成功站点数：
- 失败站点及原因：
- 异常剔除规则与数量：
- 数据文件：data/processed/xxx.csv
- 结论或观察：

备注：
```

## 四、必须记录的控制变量

真实站点实验：

- 同一台机器、同一网络、同一时段窗口
- 浏览器禁用 QUIC
- 冷缓存
- 固定重复轮数（默认 5 轮）
- 抓包与加载测量分开执行

受控实验：

- WSL 版本与内核版本
- `tc netem` 的延迟参数
- `ip route` 的 initcwnd 设定值
- 测试页面对象数与单对象大小
- 每组重复轮数

---

## 五、异常与剔除

- 剔除规则：四分位距（IQR），超出 `Q1 - 1.5×IQR` 到 `Q3 + 1.5×IQR` 视为异常
- 必须记录：剔除发生在哪个站点、第几轮、剔除前后的样本数
- 站点整体不可达：记录原因（DNS 失败、超时、证书错误），从统计中剔除，并在报告里说明
