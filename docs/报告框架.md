# 报告框架

报告按 GB/T 7713.1-2006《学位论文编写规则》组织。本文件规定章节、字数、图表位置和国标检查清单，三人按此写作，避免结构打架。

---

## 一、章节与分工

**摘要与关键词**（约 300 字，C 统稿）
研究问题、方法、主要结论各一段。关键词 4~5 个：初始拥塞窗口、慢启动、页面加载性能、网络测量、受控实验。

**第 1 章 引言**（约 700 字，A）
研究背景、initcwnd 的工程意义、本文要回答的三个问题（Q1 事实、Q2 相关、Q3 因果）、报告结构。

**第 2 章 相关原理**（约 800 字，B）
TCP 慢启动与拥塞窗口、initcwnd 与 RFC 6928、MSS 与首窗口的关系、页面加载性能指标定义（DNS、TCP、TLS、TTFB、DCL、load）。

**第 3 章 测量原理与实现**（约 1500 字，A）
抓包方案、三次握手识别、首窗口字节统计、重传去重与乱序处理、GRO/LRO 的影响与规避、算法伪代码、TCP 时序图。

**第 4 章 实验平台与指标**（约 1500 字，B）
真实站点实验流程、受控实验平台（WSL + nginx + tc netem + initcwnd 切换）、浏览器测量方案（CDP、禁 QUIC、冷缓存）、多轮统计与异常剔除、平台架构图、指标定义。

**第 5 章 结果与分析**（约 2000 字，C）
真实站点 initcwnd 分布、TTFB 与 initcwnd 的相关性、控制页面总字节后的偏相关、受控实验四组对比、两类证据的互相印证、与已有研究的对照。

**第 6 章 结论**（约 500 字，C）
回答三个研究问题、给出 initcwnd 调优建议、说明局限（样本量、网络环境、单机测量）与后续工作。

**参考文献**（C 统稿）
RFC 6928、RFC 5681、CCS/IMC 等网络测量论文、国标文件。

## 三、国标检查清单

写作完成后逐项打勾：

- [ ] 结构完整：摘要、关键词、目录、正文、结论、参考文献
- [ ] 图题在图下方，表题在表格上方
- [ ] 图表全文连续编号，正文有引用
- [ ] 表格采用三线表
- [ ] 坐标轴标注量名称与单位，量符号斜体、单位正体（GB 3101）
- [ ] 时间统一 ms，字节统一 byte，正文与图表单位一致
- [ ] 公式连续编号，符号在首次出现处说明
- [ ] 流程图与架构图符号符合 GB/T 1526
- [ ] 参考文献按 GB/T 7714-2015 著录，正文引用与文献表一一对应
- [ ] 图表文件同时提供 PNG（300 dpi）与 SVG
- [ ] 中文字体统一，正文字号统一
- [ ] 结论分级表述：相关与因果不混用

## 四、答辩分工

每人讲自己那条线，各约 5 分钟：

- A：研究问题与技术路线 → 测量算法 → 算法校准结果
- B：实验平台 → 指标定义 → 数据采集与质量控制
- C：统计结果 → 因果结论 → 创新点与局限

最后一人留 2 分钟做总结，其他人负责应答各自领域的问题。
