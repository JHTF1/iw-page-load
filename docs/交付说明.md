## 三、使用说明

1. **DOCX 目录页码**：打开后右键目录 → “更新域” → “更新整个目录”；文档已设置打开时自动更新域。
2. **PPT 讲稿**：在 PowerPoint 的“备注”窗格查看逐页讲稿；也可直接看 `答辩讲稿_A_完整场.md`。
3. **答辩口径**：真实站点只讲相关，因果只讲 lab；不要说“显著提升”“公网预期收益”。
4. **复现**：在仓库根目录运行 `python -m src.analysis`，重出图 3～6 与三张统计表；`python scripts/build_report.py` 重排 DOCX；`python scripts/build_ppt.py` 重排 PPT。

## 四、必须记住的数字

- 真实站点 25 个；initcwnd 2.29～5.15 MSS，中位数 3.78，均值 3.67；15/25 低于 4 MSS，没有站点达到 10 MSS。
- 相关：TTFB −0.183（p=0.382）；load −0.305（p=0.138）；偏相关 −0.245（p=0.249）；均不显著。
- 受控中位数：729.55 / 599.30 / 596.65 / 467.60 ms；2→10 −18.2%，2→20 −35.9%，10→20 −21.6%，4→10 −0.4%。
- 校正后 p：0.120～0.311；精确检验校正后 0.095～0.343；效应量全部 ±1.0。

## 五、数据质量提示

- amazon、yahoo 是拦截页（1 633 B / 3 669 B）。
- microsoft 的 initcwnd 只有 1/2 轮有效。
- 真实 HTTPS 首飞是配置窗口下界。
- 36kr 有 2 轮 load=0；剔除后 ρ=−0.304（p=0.139），结论不变。
- 单机单点测量，结果只代表该测量点。
