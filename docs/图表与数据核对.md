## 四、已知数据质量提示

- amazon、yahoo 为防爬拦截页（1 633 B / 3 669 B，请求数 2 / 3），加载时间不代表正常首页。
- microsoft 的 initcwnd 只有 1/2 轮有效，3.01 MSS 由单轮首飞 4 096 B 折算。
- 真实 HTTPS 首飞受 TLS 报文量限制，抓包值是配置窗口的下界。
- 36kr 有 2 轮 `load_ms=0`，按 IQR 未剔除；剔除后 load 中位数 315.0 ms，ρ = −0.304（p = 0.139），结论不变。
- 36kr、amazon、microsoft、stackoverflow、xiaohongshu、zhihu 共 6 个 HTTPS 站点存在 `tls_ms=0` 记录，该字段不参与推断。
- 所有真实站点数据来自单机、单接入点、同一时段；结果只代表该测量点，不外推全网。
